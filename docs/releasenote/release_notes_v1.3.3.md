# SonderKey 1.3.3

## Voice typing

- **You can now see that it is listening.** While recording, the suggestion strip shows a "Listening" label and a level meter that moves with your voice, so it is obvious the microphone is live rather than something you have to guess at. When you press the microphone again it changes to "Transcribing" until the text appears.
- Pressing the microphone before voice typing is set up now opens the Voice typing screen instead of doing nothing, on devices where the system has no voice input of its own.
