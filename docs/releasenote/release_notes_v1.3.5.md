# SonderKey 1.3.5

## Voice typing

- The Voice typing screen now controls **where the microphone key appears** — show it in the toolbar, pin it above the keyboard, or both — instead of sending you to the toolbar settings to find it.

## Sonder theme

- New default colours: a grey accent, mid-grey letter keys, darker function keys on a near-black plate. The teal remains available as the first accent preset.
