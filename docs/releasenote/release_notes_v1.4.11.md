# SonderKey 1.4.11

- **The handwriting plugin download button is finally visible.** The problem was never its colour: the overlay sits in the keyboard's canvas area, which is short, and its contents were taller than the space available — so the button, being last, was squeezed to almost no height and rendered as a thin bar. The button now has a fixed height, the icon and padding are smaller, and the description text shrinks first when space is tight.
