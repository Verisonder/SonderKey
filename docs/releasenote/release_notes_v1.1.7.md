# SonderKey 1.1.7

- **Emoji key on by default.**
- **The "distorted face" emoji no longer shows a placeholder box in the palette.** The bundled font has a glyph and a colour record for it, so probing the font reported success, but the artwork Google ships for it is an unfinished placeholder. It is hidden from the palette while the bundled font is in use; the character itself is unaffected and still types correctly.
