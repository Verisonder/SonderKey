# SonderKey 1.2.0

## Sonder theme

- **Two colours instead of one.** Accent controls the highlights; background controls the keys and surfaces. Deriving both from a single colour meant a strong accent tinted the whole keyboard, which is rarely what you want. Tap either chip to switch which one the presets, sliders and hex field are editing.
- Background gets its own set of presets, kept close to neutral since they cover large areas.
- **Sonder Dark is now the default night theme.**
- The Sonder theme screen has moved to the top of **Appearance** rather than sitting on the main settings list.
