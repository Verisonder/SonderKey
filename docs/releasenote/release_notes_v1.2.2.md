# SonderKey 1.2.2

## Sonder theme

**Function keys are now their own colour**, no longer derived from the letter keys. Four independent controls:

- **Keys** — the letter and number keys
- **Function keys** — shift, backspace, symbols, comma, period, emoji
- **Accent** — highlights and the enter key
- **Background** — the plate behind everything

Each is set directly, so changing one leaves the others alone.
