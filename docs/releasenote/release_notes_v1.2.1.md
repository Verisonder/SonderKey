# SonderKey 1.2.1

## Sonder theme

**Key colour is now its own control**, alongside Accent and Background. Three chips at the top of the screen switch which one the presets, sliders and hex field are editing.

- **Keys** sets the letter keys to exactly the colour picked, with no tone shifting — what you choose is what appears.
- **Functional keys** (shift, backspace, ?123, enter) are not set directly. They shift a step away from the key colour so the two rows stay distinguishable, moving in whichever direction has room.
- Key text follows the key colour's brightness automatically, so light key colours get dark labels.
