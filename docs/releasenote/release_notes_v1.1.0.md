# SonderKey 1.1.0

## Sonder design

- **New "Sonder" key style**, now the default, alongside Material, Holo and Rounded. Softer 17dp corners and a 1.5dp inset around every key for wider, more even gaps.
- **Sonder Light and Sonder Dark are now the default colour themes**, day and night.
- **The settings app has its own palette.** It no longer takes its colours from the system wallpaper — teal and graphite throughout, matching the keyboard themes, with tightened title typography.

## Emoji

- **A colour emoji font now ships inside the app.** Emoji are rendered from it rather than from the system font, so the newest emoji appear even on older Android versions. This includes the Emoji 17.0 set — distorted face, hairy creature, fight cloud, orca, landslide, trombone, treasure chest, ballet dancer and the new skin-tone sequences — on devices whose own font stops short of them.
- Can be turned off under *Appearance → Use bundled emoji font*; a font imported via *Set custom emoji font from file* still takes priority.

## Defaults

- Keyboard height: 100% portrait, 77% landscape.
- Bottom padding 104%, side padding 15% (14% landscape).
- Narrow key gaps off.
- Toolbar: Settings, Voice, Clipboard, Translate, Incognito, Handwriting, Text editing enabled by default; Undo, Copy, Paste and Select mode remain available but start switched off.

Existing installations keep their own settings — these apply to fresh installs and to anything not yet customised.
