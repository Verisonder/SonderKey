# SonderKey 1.3.2

- **The microphone key now always appears** when enabled in the toolbar settings. It was hidden, and on the keyboard itself disabled, whenever the system had no separate voice input method — which on many devices is never. Since SonderKey transcribes on its own, that check no longer applies. It still hides in password and email fields, and where an app asks for no microphone.
- Tapping it before voice typing is set up opens the Voice typing screen, so the feature is discoverable rather than silently absent.
