# SonderKey 1.3.6

- **Voice typing can be set up during first-run setup**, on the same step as the gesture typing library. One button downloads both parts, with the size stated up front, and a prompt to allow microphone access once they are installed.
- **Microphone permission can now be granted from the Voice typing screen**, rather than only being mentioned when dictation fails.
- **Finishing setup returns to the settings** instead of closing the app back to the home screen.
- The listening indicator sits centred in the suggestion strip; it previously had more space beneath it than above.
