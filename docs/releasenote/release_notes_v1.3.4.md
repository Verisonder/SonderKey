# SonderKey 1.3.4

## Voice typing setup

The Voice typing screen now states plainly whether the feature can be used.

- A status card at the top reads **Not set up yet** or **Ready to use**, and tells you how much is left to download.
- **Download everything** fetches both parts in sequence, so the two are no longer separate chores.
- The two downloads are numbered and labelled as both being required. They previously read as independent options, which made it look as though either one alone might be enough.
