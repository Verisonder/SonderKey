# SonderKey 5.1.0

## Dyslexia mode

- **For words spelled the way they sound.** Typing → Corrections → Dyslexia mode. "fone" finds "phone", "becos" finds "because", "nite" finds "night", "diffrent" finds "different".
- **Your choice of how much it does:** *Suggest the right spelling* puts the sound-alike words first in the suggestion bar and changes nothing by itself; *Correct automatically* replaces the word when you press space, with your original still one tap away and backspace undoing it.
- **Sound-alike real words** such as "wright" and "write" are only questioned when the words before clearly expect the other one, so correct words are not changed behind your back.
- Never corrects in password fields, links or email addresses. English only for now. Off by default.

## Offline translation

- **The translation plugin works again.** The current plugin translates entirely on the phone and needed support the keyboard did not have yet; that support is now in.
- **Offline language packs.** Under Words & dictionaries → Plugins, once the plugin is installed: download, delete or import the languages you translate between, about 30 MB each.
- Fixed: release builds could not load the translation plugin at all.
