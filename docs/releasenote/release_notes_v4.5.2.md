# SonderKey 4.5.2

## Autopilot

- **A favoured letter can now actually reach into the keys beside it.** Strength was capped at thirty percent of a key's width, which is roughly the size of the gap between two keys — so at full strength an expected letter filled the gap and stopped exactly at its neighbour's edge, never claiming any of it. The range is now six to sixty percent. With "Show the effect" on, the difference is visible immediately.
- Existing settings keep their number; each step on the slider is simply worth more than it was. High settings are noticeably assertive: from about eight upwards the effect applies to any press on a letter rather than only ones near a key edge. Lower it if the keyboard starts feeling like it is arguing.

Autopilot is still off by default.
