## SonderKey 1.0.0

First release of SonderKey — a privacy-first, deeply customizable keyboard.

- Brand-new Sonder Light and Sonder Dark themes
- Animated key presses
- Tuned out-of-the-box defaults (Rounded style, key borders, gesture typing, split landscape, numpad on space swipe)
- Gemini as the default AI provider (your own key, opt-in)
- Offline variants with no INTERNET permission — network access is impossible by design

Based on LeanType (LeanBitLab) and HeliBoard (Helium314). Licensed GPL-3.0.
